# Pokémon API Project

A simple project demonstrating **REST and GraphQL APIs** using the **PokéAPI**.  
The APIs fetch Pokémon data, display raw JSON, and filtered outputs.

---

## ⚡ Features

- REST API endpoints to:
  - Get a single Pokémon by name
  - Get all Pokémon names
- GraphQL API to fetch:
  - Single Pokémon with selective fields
  - List of Pokémon names with limit
- Displays **raw JSON** and **filtered data**
- Handles **status codes** for success and errors
- Uses **Axios** for API calls
- Automatically reload server during development with **Nodemon**

---

## 🛠️ Technologies Used

- Node.js
- Express.js
- GraphQL
- Axios
- Nodemon (for development)
